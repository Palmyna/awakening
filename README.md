# Project Awakening

Project Awakening est un projet de jeu mobile Free-to-Play centré sur la collection, la progression et la personnalisation de monstres représentés sous forme de cartes.

Ce dépôt contient la documentation de conception, de production et de développement du projet.

## Documentation principale

La documentation du projet se trouve dans le dossier [`docs/`](./docs/).

Le document de vision constitue le point de départ du projet :

* [`docs/00-foundation/01-VISION.md`](./docs/00-foundation/01-VISION.md)

Avant toute contribution, les agents IA doivent également consulter :

* [`AGENTS.md`](./AGENTS.md)

## Ordre de lecture recommandé

1. [`AGENTS.md`](./AGENTS.md)
2. [`docs/00-foundation/01-VISION.md`](./docs/00-foundation/01-VISION.md)
3. Les documents du dossier `docs/00-foundation/`

## Règles générales

* La documentation est rédigée en français, sauf besoin spécifique.
* Les documents du dossier `docs/00-foundation/` sont prioritaires sur les autres documents.
* Aucun document ne doit contredire la vision du projet.
* Les décisions importantes doivent être clairement distinguées des hypothèses et des questions ouvertes.
* L’état de la documentation doit être mis à jour dans ce fichier après la création ou la validation d’un document.
