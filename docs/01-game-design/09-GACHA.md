# Project Awakening — Invocation de créatures

**Statut :** Draft de conception — base initiale à compléter

## 1. Rôle et périmètre du document

Ce document rassemble les décisions validées concernant l’invocation, les raretés et l’acquisition des créatures.

Sa création est nécessaire parce que le [référentiel Créatures](./03-CREATURES.md) dépend déjà de règles d’invocation et d’obtention. Il ne fixe encore aucun taux, ensemble de familles disponibles, coût, garantie ou organisation détaillée des invocations.

## 2. Voie principale d’acquisition

L’invocation constitue la voie principale d’obtention des créatures.

Une invocation accorde normalement une nouvelle instance :

* au stade 1 ;
* dans la forme de base de sa famille ;
* au niveau 1 ;
* à 0 étoile ;
* sans point de caractéristique attribué.

Elle n’accorde jamais directement une forme évoluée.

La découverte antérieure de formes évoluées sur le compte ne modifie pas cet état initial.

## 3. Nouvelles obtentions d’une famille connue

Obtenir de nouveau une famille déjà découverte crée une nouvelle instance individuelle.

Cette instance peut :

* être développée séparément ;
* emprunter une autre branche ;
* être utilisée comme matériau d’étoiles pour une autre instance de la même famille.

Elle ne renforce pas automatiquement une instance déjà possédée.

## 4. Rareté des créatures

La rareté appartient à la famille et reste identique pour toutes ses formes et branches.

Les raretés validées sont :

1. Rare ;
2. Épique ;
3. Légendaire ;
4. Mythique.

La rareté représente principalement la difficulté ou la fréquence d’obtention, la valeur de collection et le prestige. Elle ne constitue pas une hiérarchie automatique de puissance.

Une rareté élevée peut rendre indirectement la progression en étoiles plus difficile lorsque les nouvelles instances de cette famille sont plus rares à obtenir.

## 5. Ressource générale d’invocation

Une ressource générale principale permet d’effectuer les invocations.

Elle est obtenue principalement grâce :

* au mode Histoire ;
* aux quêtes journalières ;
* aux activités ;
* aux récompenses de progression ;
* aux événements.

Elle reste entièrement séparée de l’économie cosmétique.

## 6. Acquisitions directes exceptionnelles

Certaines créatures peuvent être accordées directement par le gameplay lorsqu’une exception est explicitement documentée.

Le choix de la première créature parmi trois constitue une exception validée. Après un premier jalon du mode Histoire, une invocation contrôlée ou garantie doit également soutenir la progression initiale ; ses paramètres restent à définir.

Une acquisition directe crée elle aussi une instance individuelle selon les règles explicitement déclarées par sa source.

## 7. Capacité dépassée

Le manque de capacité ne bloque pas une invocation et ne détruit jamais une créature obtenue.

Une instance obtenue au-delà de la capacité :

* reste possédée ;
* compte comme découverte dans l’encyclopédie ;
* devient temporairement grisée et inutilisable ;
* rejoint la file selon son ordre d’obtention.

Le joueur peut continuer à obtenir des créatures lorsque sa capacité est dépassée.

## 8. Séparation du parcours cosmétique

Une invocation de créature et l’ouverture d’un paquet de skins de carte sont deux parcours distincts.

Une invocation :

* utilise une ressource de gameplay ;
* accorde une créature jouable ;
* ne doit pas être présentée comme une ouverture cosmétique.

Un paquet de skins de carte :

* accorde uniquement des skins ;
* n’utilise pas la ressource générale d’invocation ;
* n’accorde aucune créature ni puissance.

Les invocations de créatures ne sont pas vendues directement dans le modèle actuellement validé.

## 9. Articulation narrative

Une invocation établit ou révèle le lien entre le joueur et une manifestation vivante d’un écho, puis la stabilise. Elle ne crée pas artificiellement une nouvelle forme de vie.

La carte de créature reste une représentation d’interface et n’est pas un objet matériel utilisé pour invoquer.

Le vocabulaire narratif détaillé appartient au [draft Lore des créatures](../02-world/02-CREATURE_LORE.md).
